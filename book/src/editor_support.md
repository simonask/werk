# Editor Support for Werk

Editor support for Werk is currently limited to syntax highlighting.

## Zed

There is a Zed extension available in the repository:
[https://github.com/simonask/werk/tree/main/zed-werk]()

Use "Install Dev Extension" and point to the `zed-werk` directory in local
checkout of the repository to install the extension.

## VS Code

There is a VS Code extension available in the repository:
[https://github.com/simonask/werk/tree/main/werk-vscode]()

## Sublime Text

Experimental, since I don't personally use Sublime, but use
[https://github.com/simonask/werk/tree/main/werk.sublime-syntax]()
